Using Google Drive for images

  1. Upload your photo to Google Drive.
  2. Right-click the file → Share → change access to "Anyone with the link" (must be a Viewer).
  3. Click Copy link — it'll look like https://drive.google.com/file/d/FILE_ID/view?usp=sharing.
  4. Paste that whole link into the Image field above — it's converted automatically when you save.

Note: if an image doesn't load after publishing, double-check the sharing setting is "Anyone with the link" — private files never show up on the site.

Changes here are only saved in this browser until you download the file and upload it to GitHub.
